# 高校金融研究数据库：数据可用性、PIT 与量化/论文复用（2026-11-05）

> **公开学习记录（脱敏版）**。本篇整理某高校机构订阅金融数据库、校园数据库导航和公开数据资源的一次真实核验所得的方法论；不披露学校名称、机构登录信息、账号、访问网关、授权期限、具体订购明细、下载原始数据或私有项目状态。本文不是对任一高校或全部产品的授权承诺，也不是金融投资建议。

## 0. 本次核验与证据等级

- **实测通过**：在获得使用许可的高校机构入口可访问一套金融研究数据库；股票日度综合数据可进行查询和 CSV 导出，样本包含交易日、证券标识、价格/成交量、已计算收益率、若干财务指标及信息发布日期等字段。小样本导出成功只说明该查询路径可用，**不证明全历史、全市场、大批量或 API 授权已通过**。
- **权限页面观察**：同一产品可将金融研究基础库、高频**样例**和完整高频历史库分开授权；“已订高频样例”不等于获得分钟/分笔/Level-2 全量历史数据。面向金融研究的专题量化因子库也可能单独收费。
- **待核验**：宏观、行业统计、外文文献等资源在学校导航中存在，但不能仅由“引进资源”标签推断实际全部子库可下载；校外访问、导出上限、历史修订版本、第三方再分发限制均需查合同或实测。
- **公开与商业资源不能混为一谈**：CARSI 是跨机构身份认证，不是全国共享的统一采购包；公开 OA 资源无需冒用或借用其他高校账号。

## 1. 研究上优先判断“数据能做什么”，不是“库有多少”

| 研究问题 | 最小必要数据 | 需要特别核验 |
| --- | --- | --- |
| A 股/ETF 中低频因子 | OHLCV、交易日、历史股票池、停牌/退市、公司行为 | 当时可投资集合、复权语义、调整因子时点、样本外隔离 |
| 财务质量/估值因子 | 财报指标、报告期、最初披露日期、修订记录 | **财务发布日期 ≠ 完整历史 PIT 版本**；后续更正是否被回填 |
| 中国商品期货 CTA | 原始逐合约日行情、历史合约元数据、成交量和持仓量、交易日历 | 用 `t-1` 持仓量决定 `t` 的可交易合约；不要盲用事后拼接的主力连续序列 |
| 宏观—股票/产业面板 | 股票/行业数据 + 省级/月季度宏观经济、产业/能源指标 | 统计口径、空间与时间匹配、地区调整、数据修订、政策发生时间 |
| 电力市场/储能调度回测 | 预测**每次发布版本**、发布时刻、实时/结算结果、设备约束 | 不能把事后最终修订预测冒充交易决策时可知预测 |
| 事件/微观结构交易研究 | 交易所历史分钟、逐笔成交、委托或订单簿快照 | 日线不能恢复逐笔/盘口；区分免费样例、实时终端授权和历史回放权限 |

**重要原则：数据产品支持某类数据，不代表机构合同订购了该子库，更不代表支持合法大规模自动采集。**

## 2. 三个容易造成错误结论的技术问题

### 2.1 财务 PIT（Point-in-Time）与历史版本

即便日度股票表提供 `info_publication_date` 一类字段，也可能只把**最新修订后的财务值**关联到过去日期。严格的历史研究需要回答：在决策日 `t`，该数字的原始版本已经披露了吗？后续更正是什么时候发生的？

最小资格核验：抽取存在更正公告的公司—报告期，收集原公告与修订公告，对比数据库在更正之前的历史值；将 `original_vintage`、`corrected_vintage` 与实际披露时点分开。没有可重建的历史版本，就不能宣称解决 PIT 漏洞。

### 2.2 期货主力连续合约与可交易性

主力连续指数并非天然可交易合约。若研究规则是前一交易日持仓量选择下一交易日合约，则必须保留原始期货合约代码、到期规则、上一日 OI、交易日历及价格定义。不同数据商给出的连续合约切换、复权和收盘/结算价格可能不同，不能静默替换。

### 2.3 高频数据与时间戳

必须分别核实频率（分钟、逐笔）、对象（成交、委托、十档快照）、市场与年份、交易所授权、历史完整性、发布时间与采样/撮合时间、导出限制。**数据样例足够学习 schema，不足以做历史市场微观结构因果研究。**

## 3. 本轮优先级结论（非项目执行授权）

1. **优先：已有机构许可的日线金融数据库**。先完成准确的字段/版本/历史覆盖小样本核验；适合中低频投资组合研究、资产定价与基础金融计量。
2. **优先：宏观/行业统计库**。对政策与企业行为研究可补背景控制变量；不能代替核心政策处理变量、储能类型或电站实际运营结果。
3. **优先：真正公开的电力市场逐时预测历史**。AEMO 官方 Pre-dispatch 提供含预测版本的区域价格/需求等数据及历史归档；但完整历史回测仍须核对档案跨度、实际结果、时钟和设备约束。
4. **后置：高频付费升级**。在没有明确能用逐笔/Level-2 独有信息解决的研究问题前，不为昂贵授权或自制采集器投入资源。
5. **复用而非另造**：先用数据库官方导出 + Python/Pandas、R、SPSS/现有统计软件；不为缺失的付费 API 写规避权限的采集器。

## 4. 最小数据源核验卡（可以在不同项目中复用）

对每种数据源仅记录以下必要信息：

`source_name | institution_access_type | product_subdatabase | dataset_type | legal_redistribution_rules | date_range_observed | sampling_frequency | actual_freshness | fields_and_units | point_in_time_semantics | export_method | export_test_status | historical_coverage_test_status | source_revision_method | known_limits | reviewer_date`

若涉及严格因果/样本外研究，再增加：`publication_time | ingest_time | vendor_revision | data_hash | experiment_freeze_boundary`。没有证据一律写 `UNKNOWN` 或 `NOT_TESTED`，不填写虚构的 PASS。

## 5. 数据合规与公开复用

- 机构订阅数据只在授权允许的范围内访问/使用，遵守批量下载与重分发限制；其他高校账号须具备相应校方授权。
- **公开仓库只保存来源方法、通用字段示例、处理逻辑、公开网址及不包含授权样本的结果**；不公开原始 CSV、校园 IP/代理/用户名/密码/Token、账户截图、学校详细订购清单。
- 私有研究若使用机构数据，原始文件保留在获许可的本地工作区；Git 仅保存受允许的来源说明、代码与哈希/处理记录。将研究结果公开前再次核对论文与数据产品条款。
- 研究员切换数据商必须先检查语义与冻结的科学实验契约；**新数据源的发现不能用于重跑已消费样本、挽救阴性结果或查看尚未获批的样本外结果**。

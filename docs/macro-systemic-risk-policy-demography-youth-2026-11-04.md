## 0.【专项入口】金融风险管理期末论述题——素材导航，非作答

**根据另行提供的课堂范围概述**，题目集中于：
- “目前我国在哪些方面存在系统性风险？”
- “请从一个方面阐述为何可能发生系统性风险，以及如何采取管理和监管的手段和方法。”
- 老师点名：**房地产风险、地方中小金融机构风险、地方政府债务/城投平台风险、影子银行与交叉金融风险**。
- 约 **200—400字论述题**，课堂口头曾提及**约15分**，实际以正式试卷为准。

**本节只标出可用证据与机制，严格不代写论述题答案。**

| 方向 | 可能的风险积累与触发【机制】 | 关键传染链【机制】 | 可查的管理与监管手段 |
|---|---|---|---|
| 房地产 | 开发商销售与融资现金流缺口、项目交付、抵押资产价格下行 | 房地产销售/价格↓ → 抵押品价值和贷款质量承压 → 银行资本、居民财富预期及行业投资变化 → 土地收入与地方财政压力 | 项目风险分类、保交付、流动性支持与资产减值区分、银行资本缓冲、贷款集中度及压力测试 |
| 地方中小金融机构 | 区域授信集中、资产负债期限错配、关联交易和治理薄弱 | 单体资产损失/流动性压力 → 同类机构信心、存款和同业融资变化 → 被迫售资、信用收缩 → 实体经济受损 | 穿透资产质量、集中度与治理监管、早期纠正、存款保险、风险处置与资本补充 |
| 地方债/城投平台 | 土地相关收入下行、基建项目低现金回报、短债长投、隐性担保预期 | 财政现金流缺口 → 城投再融资困难 → 银行/非银及债券持有人减值 → 区域融资紧缩、投资放缓 → 税基再受损 | 全口径债务监测、预算硬约束、债务置换和重组、融资平台改革、区分债务人责任与流动性支持 |
| 影子银行 | 表外融资、嵌套与杠杆、非银资金期限/流动性错配 | 产品赎回和资产减值 → 资产集中抛售/回购收缩 → 银行与非银跨市场传染 | 金融活动穿透监管、统一风险标准、期限和杠杆约束、信息披露、流动性管理和有序处置 |

**用概念时特别注意**：金融稳定意义的**系统性风险（systemic risk）**，强调金融体系关键功能受损与跨机构传染；不应机械等同现代资产定价中的市场共同因素风险（systematic risk）。区分微观信用/市场/流动性风险和其**外部性**；观察风险的**时间维度（顺周期积累）**及**结构维度（关联网络）**，对照**货币政策＋宏观审慎政策双支柱**与单体机构微观审慎监管。

**官方规划核对【核实】**：2026—2030《十五五规划纲要》明确把**房地产、地方政府债务、中小金融机构**列为重点风险化解方向，并提出地方债全口径监测、融资平台改革、资本补充、存款保险与中小机构风险处置。见来源S1。影子银行最新监管细目须由课程AI按正式法规更新核查。

## 1. 本轮研究如何从全球危机推进到微观职业

**先后讨论过的主题**：

2. 霍尔木兹海峡、中东能源供应、国际军事与撤侨传闻；核实“实际运输受阻”与金融市场情绪是否被混淆。
3. 中国股市去杠杆、央行证券/基金/保险互换便利；区分资产市场流动性和实体经济恢复。
4. 为什么中国房地产与家庭资产负债表已经调整多年，私人需求仍然偏弱；区分市场短周期与房地产金融长周期。
5. 地方土地财政、城投平台债务化解、金融机构信用风险，以及财政与人口约束。
6. 养老金现收现付、精算预测、官方基金收支、新闻评论和社交平台争议；讨论视同缴费、农村历史农业税与养老保障差距。
7. 出生人口减少、学校撤并与事业单位人员和设施成本。
8. 不同性质实习的名义日薪与实际净现金成本、考公热、家庭福利与职业试错能力；对比日本就业冰河期。
9. 跨市场就业、升学与语言技能、金融/统计/Python复合能力和副业变现如何形成选择权。
10. “十五五”规划及AI/金融/能源/养老政策，和统计口径变化、宣传数量指标、真实收入及岗位之间的差距。

**研究共识【机制】**：金融危机是否爆发，与长期社会经济调整是否严峻不是同一问题。正增长也可以伴随居民资产缩水、财政收缩、就业质量承压；另一方面，结构性问题不能推出“全国银行和养老金必然突然崩盘”。

## 2. 全球危机：三种层次和传染机制

### 2.1 先定义不同事件

- **资产市场急跌**：股票、债券或商品估值下跌；可能没有系统性银行危机。
- **实体经济衰退**：需求、生产、就业恶化；可源于能源供给冲击而非银行倒闭。
- **系统性金融危机**：金融体系重要中介、交易和支付融资功能受严重扰动，并跨银行/非银机构传染，放大实体损失。

统一机制【机制】：

**外部/内部冲击 → 已有脆弱性（杠杆、期限错配、资产集中）→ 资产损失/保证金压力 → 被迫抛售、缩贷或挤兑 → 价格与信用负反馈 → 实体需求和就业受损。**

尤其区分：
- **流动性不足**：短期无法按时筹到现金；
- **偿付能力不足**：在合理价值下，资产/未来现金流不足以覆盖债务；
- 提供流动性或展期不等于消灭坏账；风险资产价格回升也不等于修复长期偿付能力。

### 2.2 2026年讨论过的全球触发源

**AI投资与资产估值【机制】**：巨额算力和数据中心资本开支 → 市场预期高度集中 → 企业营收/投资回报不及预期 → 股权/信用重估；若私人信贷、银行敞口和杠杆相互连接，才会提高系统性风险。需要观察实际订单、现金流、融资债务与利差，不应只凭“AI泡沫”称谓下结论。

**美元融资、美债与高利率【机制】**：通胀/财政担忧 → 长期国债收益率上升 → 长久期资产估值和抵押品价格变化 → 回购、保证金、机构融资压力；收益率上升不等于主权违约。

**能源与地缘【机制】**：霍尔木兹等航道实际运输受扰 → 油气/运费与生产成本变化 → 通胀预期上升且需求下降 → 央行面临滞胀权衡。应验证运输量、库存、油轮航线和冲击时长，不以单一匿名军事传闻证明战争扩大。

**金融网络和市场流动性【机制】**：投资者同持相似资产、同用融资工具 → 价格下降触发强制平仓/赎回 → 股票、黄金、国债等可能短期一并被卖出以获取现金。**黄金不是危机无条件上涨的工具。**

**IMF 2026年10月GFSR【核实】**：指出AI估值调整、主权收益率冲击、网络攻击，以及非银杠杆和流动性错配等风险；同时说明全球金融市场仍保持一定韧性。属于风险警示，不是对某月必定金融崩盘的确定预报。见S7。

### 2.3 历史比较：模型参照而非历史宿命

- 1929—1930年代：股灾、银行挤兑、债务通缩、货币制度约束；股价跌并非全部大萧条因果。
- 1970年代：能源供给冲击、通胀预期和利率制度共同作用，美元加息压力外溢至外币债务国。
- 1987年黑色星期一：交易策略共同动态卖出与市场微观结构，股灾不自动等于实体大萧条。
- 1997亚洲金融危机：短美元债、币种/期限错配、资本突然停止流入。
- 1998 LTCM：即使价差预期最终回归，也可能在融资和保证金约束下被迫平仓。
- 2000科技泡沫：估值与实际回报/融资持续能力分离；与AI可比的是机制，不是预设跌幅。
- 2008次贷：证券化、影子银行、短期批发融资、信用与交易对手传染。
- 2015中国股市：高杠杆与被迫卖出放大跌幅；不能仅由股灾认定全国银行体系失灵。
- 日本1990年代后：长期资产负债表修复、内需弱、就业冰河期，具有机制可比性，但中日制度和产业阶段不完全相同。

历史详论请读[前次金融危机专题](financial-crisis-macro-history-framework-2026-10-06.md)，避免重复抄写。

## 3. 中国长期调整：房地产、土地财政、城投和信用反馈

### 3.1 不能混淆三条周期

1. **经济商业周期**：需求、库存、就业与投资的相对短期波动；
2. **房地产—信用金融周期**：房价、抵押品、按揭、开发商与地方财政的长期资产负债表调整；
3. **股票融资/交易流动性周期**：融资融券、保证金、成交与市场情绪的快速去杠杆。

居民可以减少负债，政府可以增加债券融资，制造业某些部门同时扩张。不能说“所有部门同时处于去杠杆初期”。

### 3.2 2026年前三季度最新核验数据【核实】

| 指标 | 同比 / 期间 | 解释 |
|---|---:|---|
| 国内GDP，实际 | **+4.6%** | 2026年1—9月；GDP正增长不是居民财富上涨的证明；S2 |
| 房地产开发投资 | **-20.6%** | 2026年1—9月；S2 |
| 新建商品房销售额 | **-13.9%** | 2026年1—9月，金额变化不等于单价变化；S2 |
| 民间固定资产投资 | **-10.4%** | 2026年1—9月；S2 |
| 社会消费品零售总额 | **+1.1%** | 2026年1—9月；S2。**纠错：此前部分聊天误称2.6%，不得再用作同名指标** |
| 城镇调查失业率平均值 | **5.2%** | 2026年1—9月；不能表示就业质量；S2 |
| 全国企业就业人员周平均工时 | **48.3小时** | 2026年1—9月；统计对象有限；S2 |
| 国有土地使用权出让收入 | **16087亿元，-27.9%** | 2026年1—9月；政府性基金预算，不是地方净利润；S3 |
| 地方政府性基金预算本级收入 | **-22.3%** | 2026年1—9月；不是一般公共预算收入；S3 |

这些指标的组合说明**新产业/整体产出增长与地产和私人需求弱并存**。不能凭其中某一个数字就断言“全面复苏”或“已经金融崩盘”。

### 3.3 房地产—财政—金融风险链【机制】

**新房销售下降和抵押资产承压 → 开发商还款/交付压力 → 银行信用风险、住房财富效应 → 土地出让和地方可用财力承压 → 城投平台再融资及公共投资困难 → 企业回款/就业与地方税基继续承压。**

重要限定：
- 土地出让收入是政府性基金**毛收入**，包含对应征拆/开发成本与专门支出，不是自由支配净收益。
- **债务置换**能降低利息、拉长久期和减缓违约风险，不等于债务本金经济上消失。
- **法定地方政府债务、隐性债务、地方融资平台企业债务**并非同一统计对象；不能自动把平台债务视为中央政府保本承诺。
- 银行整体资本/不良率不能自动涵盖展期资产、地方中小金融机构和非银的全部潜在风险。
- 央行证券、基金和保险互换便利等市场流动性安排，不能直接证明居民消费或房地产已经复苏。

### 3.4 居民缩表与长期低增长【机制】

房地产资产预期走弱 → 家庭提前还债与预防性储蓄 → 购买住房/消费需求较弱 → 私营企业谨慎扩大招聘和投资 → 收入与税基修复较慢。

这具有“资产负债表衰退”某些机制，但不能断言中国已经完全成为日本1990年代的复制品。不同人口阶段、政策、出口与金融制度可能造成不同结果。

**识别真正恢复的标准**：房地产销量/价格、居民实际收入与消费、私营企业投资/招聘、地方财力、银行资产质量**连续多个季度**出现共同改善，而不是单次股指上涨或PMI反弹。

## 4. 养老金、人口和代际资源：不只看“是否停发”

### 4.1 现收现付的基本约束【机制】

简化关系：

**缴费人数 × 平均缴费基数 × 有效缴费率 + 财政补助及其他可用资金 = 领取人数 × 平均养老金**。

需分清：
1. 只看保险缴费时的资金缺口；
2. 计入财政补助等后的**当年收支差额**；
3. 长期精算预测中**累计储备耗尽**；
4. 未来养老金义务的现值和不同年龄队列净待遇。

即使预测出现长期缺口，也未必意味着全国立刻停止发放。可能通过财政补贴、调整退休年龄、缴费条件、养老金待遇增长方式等进行重分担；代价并非不存在，只是由谁承担的问题。

### 4.2 2025实际与2026预算【核实】

财政部预算报告S4：
- **2025年全国社会保险基金预算**收入 **126033.68亿元**、支出 **111414.10亿元**、当年结余 **14619.58亿元**；
- **2026年全国社保基金预算**预计收入 **130890.39亿元**、支出 **118144.21亿元**、当年预计结余 **12746.18亿元**。
- 两项均是**含多个社会保险险种的总口径**，不能直接当作“城镇企业职工养老金”单项基金结余。
- **全国社会保障基金理事会战略储备基金**与社会保险基金日常收支不是同一资产池，不能无条件直接相加；见S5。

2019年前后国内精算研究曾提出“2028年左右当期赤字、2035年左右累计结余可能耗尽”之类的**条件性模型预测**【待核】：此类年份必须连同原研究的险种、退休年龄、人口、缴费率及财政补贴假设引用，**不是所有养老金2035年必然崩盘的结论**。

### 4.3 机关事业单位、农村养老与隐性福利

- 机关事业单位在2014年养老保险改革前符合条件的年限可**视同缴费**；部分企业职工历史缴费转换同样存在视同缴费。不能说视同缴费仅机关事业单位独享。
- 历史农村劳动者承担农业税及部分时期的粮食义务，但这些历史贡献一般**不直接转为城乡居民养老保险的视同缴费年限**。税收与保险缴费法律性质不同，能够解释制度规则，但不能单凭此认定分配结果完全公平。
- 职业年金、住房历史福利、单位食堂和稳定退休收入可能影响家庭实际可支配资源；不同家庭是否需要承担高额赡养费用，也会改变年轻人的储蓄与就业选择。但**个别机关食堂或房改案例不能当作全国公共部门普遍待遇统计**。
- 城乡居民医保与职工医保存在筹资和保障差异；不能说全国所有农村居民都只属于某种统一“最低医疗档”。

**重要官方支出核查【核实】**：财政部2025全国一般公共预算决算S6，“行政事业单位养老支出”决算**17334.76亿元**，包含**在职人员基本养老保险缴费、职业年金缴费、对基金补助、离退休相关经费等**。不能将该总额直接除以一个假定的退休人数，声称那就是每人领取的养老金；也不能把它占一般公共预算“社会保障和就业支出”的比例称为占全国全部养老金实际发放额的比例。

### 4.4 争议报道、封号和媒体评级历史【待核】

此前讨论涉及社交媒体养老金精算帖删除/封禁、权威媒体评论的精算数据不足，以及历史企业获得AAA评级但后来出现重大信用危机的案例。

合理的证据链应分开：
- 原文和账号删除/封禁是否发生；
- 原因、时间和主体是否有独立证据；
- 精算方法和养老金预测年份是否可重复；
- 媒体报道、评级机构意见与企业真实偿债现金流是否相符。

**删文不证明模型正确，官方评论不自动否定精算压力；评论区不是代表性调查。** 不能用另一历史评级误判来断言当前养老金必然崩盘。

### 4.5 人口与学校调整【机制】

老龄人口上升、劳动年龄人口和参与率变化影响长期养老筹资；出生人口减少传导至未来劳动供给具有十几年延迟，并不是当年即减少成年缴费人数。

出生人数减少依次影响幼儿园、小学、初高中和高等教育生源；学校净减少可能有合并、调整与退出，不等于所有学校倒闭。公办学校编制与校舍存在调整刚性，部分地区短期可能有安置/维护成本，但学生和班级下降也可能节约支出。**在缺乏完整公开模型前不编造全国教师安置成本数额。**

宏观联系：养老、医保、教育调整、地方债务与地方财政收入共同竞争有限预算资源，可能影响家庭消费预期和私人企业需求。

## 5. 实习、考公与家庭保障：从微观观察到宏观反馈

### 5.1 实习经济学【机制】

讨论过两类**匿名、非代表性**实习观察：一种名义补贴不高、食宿及通勤成本低且到账规律；另一种名义补贴较高，但异地住宿、餐食、交通和长工时使实际净现金剩余相近。

比较不能只看日薪，而应看：

**净现金收益 = 实习收入 − 因实习增加的住宿、餐饮、交通等必要支出**；

**职业总价值**还要考虑获客/寻找机会、工时、课程机会成本、真实技能、研究成果、企业培训、正式岗位概率和未来工资增长。

这不等于央国企实习一定比券商好，或所有金融实习都有负收益。也要警惕“付费内推”“付费保录”的欺诈与职业操守问题。

### 5.2 家庭财务支持与社会流动【机制】

有较稳养老金/住房支持的家庭，可以更容易承担跨城市、长周期低收入的实习与求职；另一类家庭可能需要尽早获得现金收入或补贴父母。于是“同样招聘机会”并不等于相同的职业试错能力。

公共福利、住房资产、赡养负担和职业培训机会可能共同塑造**代际财富与机会差异**，但不能仅凭父母职业给家庭贴标签。

### 5.3 日本就业冰河期的借鉴【史/机制】

日本房地产/银行资产负债表调整后，1990年代及2000年代初进入就业市场的部分年轻人失去正规入职与培训机会，早期非正式雇佣可能造成持续职业**伤痕效应（scarring effect）**。后续经济恢复不一定自动补偿当年缺失的职业积累；但影响并非所有人终身同样严重。

中国目前考公/考编的吸引力，可能反映对稳定收入和风险较低岗位的需求；有限名额和财政约束使考试本身也有机会成本。**不能把考公人数的变化当作GDP衰退指标**；更不能把日本经历机械预测为中国未来30年。

### 5.4 合成谬误与宏观风险【机制】

单个人减少消费、企业控制招聘、地方压缩项目预算，在其自身约束下可能合理；但如果大量部门同时增储蓄/缩投资，可能压低总需求、订单、就业和税基，形成反馈。并非节约和财政纪律本身有错，关键是其他需求部门能否承接。

**就业数据应同时看**青年就业质量、真实薪酬、社会保险、工作时长、毕业后3—5年职业和工资变化。培训名额/见习人数不等于稳定就业。

## 6. 数字人民币与金融监管：技术能力不等于全国统一限制

本轮讨论数字人民币、财政补贴和预付资金的智能合约、可追溯和用途条件：在**特定业务和合约**中，技术能够实现资金追踪和支付条件自动执行。

应严格区分：
1. 系统技术具备条件限制与记录能力；
2. 某类专项资金已配置用途约束；
3. 所有普通个人存款和日常消费均被普遍施加用途限制。

**不能由1、2直接推出3**，也不能由数字人民币的支付治理功能推断其能够解决土地财政和养老金资金缺口。需要关注查询授权、数据最小化、救济/申诉、误冻结处理、信息披露和现金支付选择。

此次写入不把未经再次核实的2026钱包版本、普及率与交易额当成确定事实。

## 7. 国家“十五五”政策与产业机会：从规划落实到个人岗位

### 7.1 正式规划承认的结构挑战【核实】

2026—2030《十五五规划纲要》S1明确讨论：有效需求不足、供强需弱、收入与就业压力、人口结构变化、房地产、地方债务、中小金融机构和外部风险；同时布局科技创新、先进制造、金融安全、养老与公共服务、消费、财政制度和新产业。

**重要限制：政策重点≠资金已经全部拨付≠企业已经盈利≠适合毕业生的岗位已经增加。**

2026年10月国务院办公厅AI就业文件S8提出技术应用、就业创造与**减缓替代影响**并行，并涉及就业风险评估、转岗支持、灵活就业者保障。这个信号意味着政策制定同时考虑AI的生产率和劳动市场冲击，不应宣传为“只会用AI即可获得高薪”。

### 7.2 值得观察的交叉职业能力，而非直接押注某个政策赛道

| 政策或市场方向 | 金融/数据交叉岗位 | 对机会的约束 |
|---|---|---|
| AI与金融模型治理 | 风控模型、模型验证、数据质量、合规审计 | 需验证金融机构真实招聘，不是所有AI岗位扩招 |
| 先进制造与科技金融 | 企业财务、成本、供应链、估值与现金流分析 | 高产值不等于普遍利润和高薪 |
| 电力市场与能源转型 | 电价/负荷预测、能源风险、交易与结算分析 | 地方电力制度、业务和结算知识门槛 |
| 银发经济与健康保障 | 养老精算、医疗费用、保险数据与风险 | 支付方与监管价格约束 |
| 企业AI与数据自动化 | Office批处理、质量复核、企业数据治理 | 通用安装和提示词易被免费/成熟产品替代 |
| 金融安全与地方债务 | 信用、市场、流动性、资产负债管理 | 风险需求存在不代表岗位有同等增长 |

共同底座：**英语专业沟通 + 概率统计/计量 + Python/SQL + 金融风险与财务分析 + 数据质量/模型验证 + 实际可复现成果**。

学习选择应基于真实JD岗位要求、毕业生实际招聘、工资与生活成本。高费用境外硕士不是自动的风险对冲；资助项目、国内升学和优质直接就业要按净成本与机会价值比较。

副业/变现经验的公共结论：**先验证付款意愿，再产品化与自动化**；优先现成工具和有边界的客户成果，不为“睡后收入”先行开发复杂商城、授权和营销基础设施。具体商业安排与个人财务均不进入本公开档案。

## 8. 官方报告与社交媒体必须使用同一套统计审计标准

### 8.1 失业率与灵活就业：重要的纠错

**灵活就业人员并非被调查失业率“一律排除”。** 符合就业调查定义、参考周为获得收入工作达到就业认定标准的灵活就业者可计为“就业”；失业须符合未就业、求职和可上岗等条件；没有工作但未找工作者可能是非劳动力人口，不进入失业率分母。

2024年以后公开的16—24岁等分年龄组失业率注明**不含在校学生**，和此前口径不可机械连接。**失业率≠充分就业率≠体面就业率。** 低工时、低薪与收入不稳定可能仍被统计为就业。

补看：劳动参与率、就业人口比率、工时、工资中位数、社保参保、稳定职位、毕业3—5年的职业积累。不要简单把灵活就业人数当成“全部隐形失业”。

### 8.2 脱贫与返贫监测

达到某一历史贫困标准下的脱贫目标，不等于之后不存在相对贫困、因病致困或返贫风险；后续常态化帮扶监测可能采用不同标准、对象和动态进出条件。需要核对门槛、收入、医疗与教育负担、覆盖范围，不能因为改名就必然判定为数据造假，也不能把“当年脱贫”当成永久消除生活困境。

### 8.3 关键口径错误列表

- 社会保险基金**保费、财政补助、总收入、当期结余、累计结余、未来精算负债和战略储备基金**不同。
- 机关事业养老预算包含在职缴费和基金补助，**不等于退休人员现金养老金**。
- 土地出让毛收入不等于净财政自由现金；一般公共预算与政府性基金预算不同。
- 法定地方债务、城投企业债务、隐性债务不能随意相加或假设全部中央兜底。
- **实际GDP增速**、名义零售额、投资额、工业利润增长的统计基础不同。
- 平均收入不等于中位数；总就业人数不等于高质量正规就业。
- 项目申请额度/政策投资目标不等于完成投资和企业净盈利。
- 未核实社交账号删文封禁与某精算结论的因果关系；媒体评级历史经验不等于另一案件的必然结论。
- **本次数据复核特别纠错**：2026年前三季度社会消费品零售总额同比为**+1.1%**，而非同名指标**+2.6%**。见S2。

分析每个指标必须说明**主体、样本、分子分母、名义/实际、时间窗口、可比口径、是否修订、政策目标还是执行结果**。

## 9. 综合预判：全球冲击与国内长期调整下的适应能力

以下均是**条件性情景【机制】，不是概率预报**：

**情景A：结构缓慢修复**——房地产销售和财政压力逐渐企稳，私人投资、消费与就业开始广泛改善；市场化高成长岗位和产业数据分析机会增加。

**情景B：正增长但需求与青年就业长期承压**——地方财政支出刚性和养老压力、家庭预防性储蓄、低回报投资共同限制私人岗位；人才可能遇到就业伤痕。政策维持金融稳定并不等于职业机会广泛改善。

**情景C：全球资产/能源/融资冲击**——AI相关信用风险或国债收益率、能源通道冲击经外需、成本和金融市场传至中国；需要观察全球融资条件和国内金融机构的实际传染，不能以指数下跌断言金融体系崩溃。

**三情景的共同技能对冲**：英文金融/技术信息获取，扎实统计建模与风险解释，Python/SQL处理真实数据，质量审查和可复现研究，能够跨金融、产业和数据岗位使用。提升职业选择权，而不是为未知危机做难以退出的高杠杆押注。

**未来观察板**：全球信用利差/美元回购、能源实际供应；中国房地产销量/投资、民间投资、居民实际收入与消费、地方土地收入/债务付息、企业岗位及净工资、社保分险种数据。必须有连续时间趋势和同口径证据。
